# Optional walkthrough — spoilers

1. Examine the starting ticket.
2. Enter the waiting room to the left. Read the notice and notebook; collect the blue promise memory.
3. Head into the garden beside the room. Follow the stepping stones toward the maintenance shed.
4. Collect the departure memory under the garden tree. Take the reserve cell from the shed workbench and read the maintenance record.
5. Return to the northern end of the main platform. Set the relay to Lantern 2, Rain 1, Dawn 3; close the circuit.
6. Cross the unlocked Signal Walk and view the floating world.
7. Find the third blue memory beside the overlook bench.
8. Play HOME, NAME, LIGHT at the signal console.
9. Return to the platform as the train arrives. Speak to the stranger, then use the boarding prompt near the platform edge.
10. An optional fourth memory is near the vending-machine end of the platform. You can return after the ending to find it.
