# Platform Zero — character update (v0.2.0)

The traveler now has an original anime schoolgirl model, replacing the primitive chibi figure while preserving the quiet, muted palette and small leather backpack.

- Shaped face and jaw, almond eyes, layered blue-black bob and a small brass hair pin.
- Ivory sailor blouse, navy collar and pleated skirt, rust ribbon, dark socks and loafers.
- Articulated elbows/knees, smooth blinking, gentle hair/ribbon motion, and stride-responsive skirt movement.
- Original glTF asset included offline, with a reproducible Python authoring script; no external model downloads or asset licenses required.
- Movement, jumping, analog auto-run, camera and saved progress retain their existing behavior.

Version 0.2.0 / Android version code 3. Uses the existing package ID and development signing key for installation over v0.1.1.

Godot 4.5.1 import, gameplay/multitouch smoke tests and desktop software-rendered character checks passed locally. The release workflow also runs the smoke tests, exports ARM64 Android and verifies the APK signature before publishing. Physical Android appearance and performance still need device testing.
